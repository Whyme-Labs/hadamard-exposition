# Hadamard exposition

A reproducible study of Hadamard changes of basis and quantization error.

The project combines an illustrated exposition, exact mathematical checks, and bounded synthetic CPU experiments. It began with the 17 October 2026 exposition package and is tracked in this repository's GitHub issues and pull requests.

The current milestone imports the completed article and reference experiment, then measures how the result changes when each quantization scale covers fewer input features. Experimental results and their limits will be retained with the code.

The related Lean execution qualification is owned by [autoresearch-harness issue #175](https://github.com/Whyme-Labs/autoresearch-harness/issues/175) and [PR #176](https://github.com/Whyme-Labs/autoresearch-harness/pull/176).
