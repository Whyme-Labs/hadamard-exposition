# Domain documentation

Use the single root `CONTEXT.md` for vocabulary, scope and the research objective. Put frozen experiment designs in `docs/experiments/` and retain their source hashes in result receipts. Put measured results and interpretation in the article and the owning GitHub issue.

An algebraic identity, a floating-point check, a synthetic error measurement, and an application benchmark support different claims. State the exact quantity each check establishes. Keep group size, quantizer codes, scale rules, sign selection, seeds and output metric explicit.

A source file or report hash establishes byte identity. It does not establish mathematical correctness. Independent numerical controls and review assess the experiment itself.
